# Surfaces downloads

Surfaces helps you inspect application builds, turn design feedback into reusable guidance, and deploy completed builds locally.

This repository contains macOS release downloads and installation notes. The application source is maintained separately.

[Alpha releases](https://github.com/mikeylong/surfaces-releases/releases) · [Installation and scope](RELEASE_NOTES.md)

Download the Apple-silicon ZIP and its SHA256SUMS from the same release. Extract the ZIP, move Surfaces to Applications and open it. First launch prepares the local build environment.
